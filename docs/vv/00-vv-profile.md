## 2. ระบบของเรา

- ระบบนี้ทำอะไร (2–3 ประโยค): 
ระบบ P6 เป็นระบบบริหารจัดการข้อมูลสะท้อนกลับและความพึงพอใจของผู้มีส่วนได้ส่วนเสียของหลักสูตรวิศวกรรมซอฟต์แวร์ โดยรองรับการสร้างแบบสำรวจ การเปิดรอบการสำรวจ การรวบรวมคำตอบ และการสรุปผลความคิดเห็นจากผู้มีส่วนได้ส่วนเสีย นอกจากนี้ยังช่วยให้ผู้รับผิดชอบสามารถวิเคราะห์และจัดหมวดหมู่ประเด็นปัญหา เพื่อนำข้อมูลไปใช้ประกอบการพัฒนาหลักสูตรและเชื่อมโยงข้อมูลกับระบบ P1/P2 ได้
- ผู้ใช้หลักและผู้มีส่วนได้ส่วนเสีย (ใครใช้ ใครได้รับผลกระทบ): 
ผู้ดูแลระบบและผู้รับผิดชอบหลักสูตร: จัดการแบบสำรวจ รอบการสำรวจ และตรวจสอบผลการตอบแบบสำรวจ
ผู้รับผิดชอบการวิเคราะห์ข้อมูล: วิเคราะห์และจัดหมวดหมู่ความคิดเห็น รวมถึงคัดเลือกประเด็นปัญหาเพื่อส่งต่อไปยังระบบที่เกี่ยวข้อง
นักศึกษาปัจจุบัน: เป็นกลุ่มผู้ตอบแบบสำรวจและให้ความคิดเห็นเกี่ยวกับหลักสูตร
ศิษย์เก่า: ให้ความคิดเห็นเกี่ยวกับความรู้และทักษะที่ได้รับจากหลักสูตร
สถานประกอบการหรือผู้ใช้บัณฑิต: ให้ความคิดเห็นเกี่ยวกับความสามารถและทักษะของบัณฑิต
อาจารย์และผู้เกี่ยวข้องกับหลักสูตร: นำผลการประเมินไปใช้ประกอบการปรับปรุงหลักสูตร
- ผู้ใช้จริงที่จะชวนมาทำ UAT ได้ (หน่วยงานหรือกลุ่มผู้ใช้ ไม่ต้องใส่ชื่อบุคคล):
อาจารย์ผู้รับผิดชอบหลักสูตรวิศวกรรมซอฟต์แวร์
เจ้าหน้าที่หรือผู้ปฏิบัติงานที่เกี่ยวข้องกับการบริหารจัดการหลักสูตร
ตัวแทนนักศึกษาหลักสูตรวิศวกรรมซอฟต์แวร์
ตัวแทนผู้รับผิดชอบการรวบรวมและวิเคราะห์ข้อมูลสะท้อนกลับ
- การ deploy (ทดสอบที่ไหน ใช้งานจริงที่ไหน):
การทดสอบ: Deploy ระบบในสภาพแวดล้อมสำหรับทดสอบ (Testing Environment) เพื่อให้ผู้พัฒนาและกลุ่มผู้ใช้ทดลองใช้งาน ตรวจสอบการทำงาน และดำเนินการ UAT
การใช้งานจริง: มุ่งเน้นการทดลองใช้งานในระดับนำร่อง (Pilot) กับกลุ่มผู้ใช้ที่เกี่ยวข้องกับหลักสูตรวิศวกรรมซอฟต์แวร์ โดยยังไม่ใช่การเปิดใช้งานเต็มรูปแบบในระดับมหาวิทยาลัย
